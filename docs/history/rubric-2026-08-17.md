## Two amendments this sheet cannot make for itself

Rubric rule: *"Change the weights here, by commit, never in a review."* So these
are proposals, not applied.

1. **The rubric measures one library.** `packages/mobile` is 145 widgets, 669
   tests, five gates and a docs pipeline, and it enters this sheet only as a
   rounding adjustment on C1, E2 and G3. Every A-criterion is phrased in served
   HTML, which a Flutter app does not produce. Either A gets platform-neutral
   wording ("in the delivered output — served HTML on web, semantics tree on
   mobile") or the sheet grows a mobile column scored on the same anchors.
2. **G3's anchor names React Native.** Decision §30 chose Flutter and removed
   the RN package. The anchor should read "a first-class mobile story, gated"
   rather than naming a framework the project deliberately rejected.
