# Website logo assets

All horizontal and vertical SVGs are byte-identical to the 12 October 2026
folded-L masters in assets/logo. The symbol and outlined Inter wordmark retain
fixed ink/paper/lime colours. Theme changes choose the matching supplied asset.
Symbols stay left in every locale and never mirror or receive CSS recolouring.

The owner explicitly commissioned this new identity in the geometric direction
of Telarsa and Khatamo. The wordmark is outlined and requires no browser font.
Source/OFL notice and offline generator are documented in assets/logo.
render-brand-images.mjs reads the current symbol master to generate every
favicon, home-screen icon and share image.

Persian masters add -fa to horizontal/vertical filenames and spell the
owner-confirmed «لومو یو‌آی». HarfBuzz joins the glyphs before outlining them
from the included Vazirmatn-Bold/OFL source; no proprietary font is read.
The shared symbol stays left. The website chooses Persian masters on fa.
