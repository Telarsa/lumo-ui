# Website logo assets

`lumo-lockup-on-paper.svg` and `lumo-lockup-on-ink.svg` are exact copies of the
delivered masters in the repository's `assets/logo/`. Their symbol stays on the
left in every language. Theme changes select the matching supplied asset;
they do not recolour or mirror it.

The two `lumo-lockup-vertical-*` files are website layout derivatives for the
footer. They preserve the masters' mark paths, fixed ink/paper/lime colours and
Archivo wordmark attributes; only placement and the view box change. The
delivered wordmark is live SVG text with its original system fallback. No
outlined wordmark or Archivo font file was supplied, so consistent outlined
masters remain an owner item.
